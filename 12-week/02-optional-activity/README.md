# Explicación breve

# 1¿por qué usaste Map?

Para este ejercicio utilicé Map porque permite almacenar información usando una clave única.  
En este caso, el código del producto funciona como clave para acceder rápidamente a los datos sin recorrer toda la colección.

También utilicé otro Map para manejar las cantidades de stock de cada producto.  
Esto facilita actualizar entradas y salidas de inventario de manera organizada.

# 2¿qué problemas resolvería Set en otro contexto? 


Un Set podría servir en otro contexto para evitar elementos repetidos automáticamente.  
Por ejemplo, sería útil para almacenar categorías únicas o códigos sin duplicados.

# 3¿qué errores comunes evitaste al iterar?

Durante el desarrollo evité errores comunes al iterar verificando primero si el código existía dentro del Map antes de acceder a la información.  
También controlé casos como stock insuficiente y productos inexistentes para evitar fallos en la ejecución.

Gracias al uso de colecciones, el programa puede agregar, buscar, actualizar y listar productos de forma más eficiente y ordenada.
